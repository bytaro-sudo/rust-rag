# Rust RAG: Retrieval-Augmented Generation System

This repository contains a modular implementation of a RAG (Retrieval-Augmented Generation) system in Rust, designed with a focus on performance and memory efficiency.

## About the Project

This project is part of an educational series on implementing RAG systems in Rust. The goal is to document the learning and development process from scratch, showing both the challenges and solutions encountered along the way.

## Structure

The system is divided into functional modules:

- **Chunking**: Splitting documents into manageable fragments
- **Embedding**: Generating vector representations of text
- **Indexing**: Processing and indexing documents
- **Storage**: Efficiently storing vectors for search
- **Retrieval**: Retrieving relevant information
- **Generation**: Integrating with LLMs to generate responses

## Current Status

This project is in active development. Currently implemented:
- [ ] Basic document chunking
- [ ] Embedding via external models
- [ ] Simple vector storage
- [ ] Cosine similarity retrieval
- [ ] LLM API integration
